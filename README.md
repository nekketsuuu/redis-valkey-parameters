# Redis & Valkey Parameters

Compare Redis & Valkey parameters by version.
<https://nekketsuuu.github.io/redis-valkey-parameters/>

## How

Parameters are collected from the official Docker images.
The page is written in Ruby and runs in the browser on PicoRuby.wasm: <https://github.com/picoruby/picoruby>.
