Notes:
  • Values are the output of CONFIG GET * on servers started without a configuration file from the official Docker images (redis, valkey/valkey).
  • protected-mode: The official images patch the default to no at build time, but the default defined in the upstream source code (yes) is displayed instead.
  • dir: The working directory of the images, /data, is stored as is.
  • Aliases: Since Redis 7, CONFIG GET * also returns aliases such as slave-* and *-ziplist-*, and they are shown in the table as is.
  • Links: Aliases and some module configurations have no link because they are not described in the configuration files.
